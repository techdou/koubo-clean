# 口播清理报告模板

每次清理完，把报告贴给用户（用实际口播内容描述，不用 `[sN]` 等内部编号）。

```markdown
## 口播清理报告：<视频/课程名>

**成片时长**：<原> → <新>（缩短 Xs）

**已剪（口误型）**
- “<原话>” → “<剪后话>”（<大概位置>）

**保留（教学/强调/用户指定）**
- “<原话>”

**字幕修正（音频不动）**
- “<旧字幕>” → “<新字幕>”（品牌词/ASR 错词）

**待确认（pending）**
- “<疑似词>” 疑似 “<猜测>”，位置：<时间点>
```

待确认项同时追加到项目根目录的 `pending-words.md`，供用户一次性核对。
