# 口误模式库

剪口播时按以下模式扫描成片文本，命中候选后对照“该剪 / 不剪”标准决定是否剪。拿不准的进待确认清单。

## 1. 叠字（直接剪）

- 双字叠：把把、呃呃、很很、自自己、一一种、操…作、都都都
- 词尾重复：封装好好 → 封装好、操作操作平台 → 操作平台
- 重复短语中夹叠：prompt 我们的 prompt → prompt、模型模型 → 模型

## 2. 半截词改口（直接剪）

- 说半个词又补全：一个技，一个技能包 → 一个个技能包；它也是一个插，它也是一个接口 → 它也是一个接口
- 先起头又改口：告诉说，告诉这个 agent → 告诉这个 agent
- 中英夹说重复：workflow 工作流（讲解性除外，教学保留）

## 3. 紧邻同义重复（直接剪，二选一）

- 肯定…肯定；这个…这个；更早的开始，更早的开始
- 遇到相同的问题，遇到相同的问题；而不是说…而不是说；就完全的自主了 ×2
- 问题本身模糊，就是需求本身模糊；未来以后
- 能力的边界，模型的边界（用户明确保留示例，不剪）

## 4. 改口残留（直接剪）

- 那回到我们，；甚至说现在很火的，现在说；像感啊；我们…我们
- 一句话没说完又重起：我们需要把它的边界。（无下文）

## 5. 填充词（看密度，不机械删）

- 呃 / 嗯 / 啊 / 是不是？：单次出现保留；连续两个以上（呃呃、啊、啊）剪到最多一个；口头禅式高频（是不是？）按用户偏好处理

## 6. 不剪（保留）

- 教学演示重复：拆成…拆成…、生成…生成…（演示流程）
- 递进强调：封装成了技能包的形式，封装成了使用说明
- 排比列举：做一个APP做一个小程序做一个网页；独特的观点、独特的处理流程
- 跨句/跨段语义重复：先列清单给用户确认，不擅自删

## 扫描方式

1. `read_script` 拿当前成片文本
2. 按 1–4 类模式找候选，标出位置（用实际口播内容描述）
3. 强候选直接剪；中候选（完整的同义句）列给用户确认；ASR 疑点进待确认清单
